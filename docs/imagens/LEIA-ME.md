## Como registrar

O requisito do challenge é uma imagem **ou** vídeo do agente rodando **em nuvem**
— não basta o print local. Grave depois que a aplicação estiver no ar na OCI, com
o endereço público visível na barra do navegador: é isso que comprova a execução
remota.

Roteiro sugerido para o vídeo, cobrindo os quatro comportamentos que distinguem o
projeto:

1. Uma pergunta de catálogo — "quais carros custam até 70 mil?"
2. Uma simulação de viagem — "quanto gasto de São Paulo ao Rio com o Corolla?"
3. Uma pergunta ao manual do proprietário — "de quantas em quantas revisões troca
   o fluido de arrefecimento do Corolla?"
4. Uma pergunta fora do escopo — "quanto gasta o Fiat Uno?" — para mostrar que o
   agente recusa em vez de inventar

Para gravar a tela: OBS Studio, ou a própria gravação do sistema. Vídeo commitado
no repositório pesa; se passar de uns 10 MB, prefira subir no YouTube como *não
listado* e colocar o link.

Arquivos desta pasta **entram no repositório** — o `.gitignore` não os exclui.
